Return & Refund Policy

We want you to love every Sakhi kurti. If something's not right, we'll make it right.

🔄 7-Day Return Policy

We offer a 7-day return window from the date of delivery. If you're not satisfied with your purchase for any reason, you can return it hassle-free.

Return is accepted if:

  • Product is unused and unwashed
  • Tags are intact
  • Original packaging is present
  • Return request is raised within 7 days of delivery

Once we receive and verify the product, refund will be processed within 5-7 business days.
